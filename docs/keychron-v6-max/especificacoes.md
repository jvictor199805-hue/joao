# Especificações técnicas

| Item | Especificação |
|---|---|
| Modelo | Keychron V6 Max (Fully Assembled Knob) |
| Marca | Keychron |
| Layout | Full-size 100% (ANSI, 108 teclas) com knob programável |
| Conexões | 2.4 GHz (receptor USB), Bluetooth 5.1, USB-C com fio |
| Taxa de resposta | Até 1000 Hz no modo 2.4 GHz e com fio |
| Bluetooth | Até 3 dispositivos simultâneos, troca por Fn + 1/2/3 |
| Firmware | QMK (open source), configurável via Keychron Launcher (web) |
| Hot-swap | Sim, sockets compatíveis com switches MX de 3 e 5 pinos |
| Switches | Gateron Jupiter pré-lubrificados (Red, Brown ou Banana), vida útil de até 80 milhões de acionamentos |
| Keycaps | PBT double-shot, perfil OSA, não translúcidas |
| Montagem | Gasket mount |
| Placa (plate) | Policarbonato (PC) |
| Acústica | Camadas de espuma IXPE, PET e látex |
| Estabilizadores | Parafusados (screw-in) |
| Iluminação | RGB south-facing, efeitos configuráveis |
| Bateria | 4000 mAh recarregável |
| Autonomia | Até 300 h (backlight desligado), aprox. 100 h com iluminação moderada |
| NKRO | Sim (n-key rollover) |
| Compatibilidade | macOS, Windows e Linux, com seletor físico Mac/Win |
| Cor | Carbon Black |
| Itens na caixa | Teclado, cabo USB-C, receptor 2.4 GHz, keycaps extras Mac/Windows, extrator de keycaps e switches, manual |

## Observações

- Valores de autonomia variam conforme brilho do backlight e modo de conexão.
- A versão barebone (sem switches e keycaps) e variantes ISO existem no site oficial; a página de referência deste projeto é a versão montada ANSI.
