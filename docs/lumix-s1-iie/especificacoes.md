# Especificações

Ficha técnica da Lumix S1 IIE (DC-S1M2E). Valores informados pelo fabricante e por reviews independentes; confirme na página do produto.

## Sensor e foto

| Item | Especificação |
|---|---|
| Sensor | Full-frame 24,2 MP BSI CMOS |
| Montagem | L-Mount (Panasonic, Leica, Sigma) |
| ISO | 100 a 51.200 nativo, expansível 50 a 204.800 |
| Estabilização | 5 eixos no corpo, até 8,0 stops (centro) e 7,0 (periferia) |
| Autofoco | Phase Hybrid, 779 pontos, reconhecimento por IA |
| Rajada | 10 fps (mecânico) e 30 fps (eletrônico), com AF contínuo |
| Alta resolução | 96 MP com a câmera na mão |

| Item | Especificação |
